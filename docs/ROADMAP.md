## Зависимости и риски

- **Историческая достоверность:** заявленный объём 8–10 мест, 16–20 статей и 16–20 событий — ориентир, не повод выдумывать сведения. Наполнять постепенно и публиковать только проверенное. Аналогично 4–6 пар «тогда / сейчас» допустимы лишь при найденных и корректно атрибутированных материалах.
- **География:** хронология описывает всю войну, карта — только подтверждённые точки современного ЗАО. Не смешивать общую историческую хронологию с географической выборкой.
- **Даты:** основной показ событий 1812 года — по старому стилю; новый стиль показывается рядом при наличии проверенного соответствия. Оба значения хранятся явно; отдельный `sortDate` не должен получаться неявным преобразованием календаря.
- **Локализация:** EN факты требуют полноценного перевода; частичная англоязычная запись не должна создавать индексируемую страницу.
- **GitHub Pages:** имя репозитория и публичный домен определяют `baseURL` и canonical. Прямой заход на вложенные маршруты проверяется после генерации; 404 fallback не является SEO решением.
- **Яндекс Карты:** нужен клиентский API ключ и проверка актуальных условий/лимитов перед Stage 6. Ключ виден браузеру; его ограничивают по домену. Нет ключа — текстовый fallback.
- **Изображения:** права использования и атрибуция требуют отдельной проверки; placeholder явно обозначается и не маскируется под историческую фотографию.
