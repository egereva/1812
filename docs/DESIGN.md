# Визуальная система

## Stage 5 — Timeline presentation hierarchy

Regular компактен, featured усиливает существующий production flag, landmark определяется шестью stable IDs в отдельном presentation config. Landmark разрывают alternating rhythm: burgundy типографические паузы, ivory artwork/text и wide artwork, graphite artwork/text. Между ними сохраняется chronological axis; DOM всегда следует sortDate → id. Tablet/mobile — одна колонка. Все artwork показываются целиком, с читаемой caption и тихой attribution/source; используется общий MuseumImageViewer. Отсутствующее artwork не создаёт placeholder. Полный mapping и причины landmark: [Stage 5 art-direction](research/timeline-stage5-art-direction.md).

Homepage Timeline не использует номер секции. Desktop >1024 px: шесть curated landmark точек образуют горизонтальную ось; hover/focus/tap выбирает editorial split примерно 52% text / 48% contain artwork с quiet caption/attribution. Active отмечен размером точки, подчёркиванием и aria-pressed. Text/artwork получают мягкий fade; reduced motion отключает переход. Mobile/tablet ≤1024 px: отдельная native horizontal strip со scroll snap, скрытым scrollbar и частично видимым следующим item. Каждый event — прямая detail link с artwork при наличии, date и short title; Tab/focus прокручивает ссылку в видимую область. CTA отдельно под strip, page overflow и autoplay отсутствуют. Curated subset теперь независим от полной Timeline: Неман → Бородино → Фили → выход из Москвы → Малоярославец → Березина. Coverage **6/6**, включая approved original Кларка/Дюбурга 1816 года; mapping описан в [refinement audit](research/homepage-timeline-stage5-refinement.md). Это заменяет прежний preview из четырёх колонок с номером 03/04.

Stage 2: современный цифровой музей в редакционной манере. Характер создают крупная типографика, простор, датировка, тонкие линии и точные подписи. Сайт должен оставаться цельным без фотографий. Пергаментные текстуры, золото, декоративная «старина», имитации карт и военный плакатный стиль не используются.

## Где находится реализация

Timeline detail имеет собственную временную идентичность: primary old-style date/range, quiet supplied new-style date/range, H1 и lead над divider. Desktop article/media — сетка 58/42; artwork целиком через общий viewer, высота ограничена 32rem. На ≤900 px media/caption предшествуют статье; без image остаётся текстовая колонка до 46rem. Related, historical sources и chronological previous/next — текстовые ссылки и тонкие линии, без карточек. Пустой media slot и искусственная минимальная высота отсутствуют.

- `app/assets/css/tokens.css` — единый источник значений CSS custom properties.
- `app/assets/css/main.css` — небольшой reset, типографика, контейнеры, оболочка и адаптивные правила.
- `app/layouts/default.vue` — skip link, один `<main id="main-content">`, header и footer; выставляет `html lang`.
- `app/components/SiteHeader.vue` и `SiteFooter.vue` — навигация, язык, идентичность; набор основных ссылок в `app/utils/navigation.ts`.
- `i18n/locales/{ru,en}.json` — только короткие подписи интерфейса. Название и описание проекта берутся через content layer из production `site.json`.

| ---------------------------------------- | --------------------- | ------------------------------------------ |
| `--color-bg`                             | `#f3f0e8`             | тёплый светлый фон                         |
| `--color-surface`                        | `#fbf9f4`             | поверхность раскрытого меню                |
| `--color-ink`                            | `#1c1b19`             | основной текст                             |
| `--color-muted`                          | `#56534e`             | вторичный текст                            |
| `--color-accent`                         | `#702837`             | бордовый акцент, фокус, активное состояние |
| `--color-accent-hover`                   | `#501c28`             | запасной более тёмный акцент               |

Основные пары текста проходят WCAG AA: ink/background ≈ 15.1:1, muted/background ≈ 6.7:1, accent/background ≈ 9.0:1, footer text/footer ≈ 13.0:1. Линия не служит единственным индикатором состояния.

## Шрифты и шкала

`--font-display`: Iowan Old Style → Baskerville → Palatino Linotype → Georgia → serif. Роль: заголовки, крупные даты, слово `1812` и будущие выразительные цитаты. `--font-body`: Segoe UI → Helvetica Neue → Arial → sans-serif. Роль: основной текст, меню, подписи и управление. Сейчас нет внешней загрузки шрифтов или бинарников; стеки проверены на кириллице и латинице в доступной системе. Позднее замена возможна только с проверенной лицензией, локальным файлом и тестом обеих письменностей.

В `tokens.css` определены `display-xl`, `display-lg`, `h1`–`h3`, `body-lg`, `body`, `body-sm`, `caption`, `overline`. Крупные роли используют `clamp()`. Главная берёт `siteTitle` и `siteDescription` из production контента; единственный H1 находится в hero.

## Пространство и сетка

Шаг отступов: 4, 8, 12, 16, 24, 32, 48, 64, 96 px через `--space-*`. Горизонтальный gutter fluid: `clamp(1rem, 4vw, 4.5rem)`. Максимумы: page 1440 px, wide 1600 px, text 736 px; их задают `.page-container`, `.wide-container`, `.text-container`. `.full-bleed` оставлен для будущих полноширинных областей. `--grid-gap` задаёт общий зазор композиционной сетки. Большие секции разделяются пространством и линиями; теней нет. Радиус контроля — 4 px; контент не оформляется в набор закруглённых карточек.

Перестройка оболочки: до 900 px основное меню раскрывается кнопкой, до 600 px уменьшаются заголовки и футер становится одноколоночным. На 320 px сохраняются отдельно слово `1812`, языки RU/EN и кнопка меню. Внутренние компоненты будущих этапов должны выбирать перестройку по содержимому, не добавляя множество точечных breakpoint. Не допускать горизонтального переполнения страницы.

## Навигация и доступность

Header содержит типографический wordmark, пять основных маршрутов и переключатель языка. Активная ссылка имеет нижнюю линию и `aria-current="page"`; страницы `/places/[slug]` относятся к разделу «Карта». На мобильном меню скрыто через `display: none`, открывается настоящей кнопкой с `aria-expanded` и `aria-controls`. При открытии фокус переходит на первую ссылку; Escape закрывает меню и возвращает фокус кнопке; переход по маршруту закрывает меню. Ссылки ведут через `useLocalePath`, язык меняется через `useSwitchLocalePath`, поэтому стабильный slug сохраняется на соответствующей RU/EN странице.

Первой в DOM идёт ссылка пропуска к `#main-content`. `:focus-visible` сохраняет отчётливый двухпиксельный контур. Навигация и языки имеют зону нажатия не меньше примерно 44 px; элементы меню — выше. Состояния не зависят от hover. Короткие переходы ограничены 180 ms; `prefers-reduced-motion: reduce` почти полностью отключает анимацию и плавную прокрутку. Header, footer и текущие технические detail страницы работают без изображений.

## Медиа и следующие этапы

В Dictionary detail и image viewer caption (включая существующее пояснение к изображению) остаётся первой, читаемой строкой. Вторая строка тише и меньше: collection/institution · rights/license · inline source link. Повтор автора из caption убирается только в presentation; отдельная атрибуция неизвестного автора сохраняется. Исходные metadata и `sources.json` не меняются.

Image viewer использует графитовый фон `#252628`, светлые тонкие иконки без декоративной toolbar и controls минимум 44×44 px. Artwork вписывается целиком с полями; zoom ограничен исходным разрешением. Caption/description/credit/source находятся отдельно в нижней зоне, её измеренная высота исключается из области изображения; длинные подписи прокручиваются внутри ограниченной панели. `app/assets/css/museum-viewer.css` переопределяет PhotoSwipe chrome, `MuseumImage` даёт semantic button с zoom-in cursor и маленькой иконкой только на hover/focus. Один asset не показывает стрелки/counter; несколько получают ArrowLeft/ArrowRight, две стрелки и counter. Reduced motion отключает переходы, фон inert, Tab остаётся внутри dialog, закрытие возвращает focus к изображению.

Глобальное правило задаёт `img { max-width: 100%; height: auto; }`; три одобренных hero-файла доступны локально. URL из editorial media manifest не становятся runtime `src`. Архивное, документальное и более позднее художественное изображение должны получать точную подпись и атрибуцию. Художественное изображение нельзя подавать как фотографию события.

Stage 3 использует полноширинное историческое изображение как главное поле hero. Только на Homepage полупрозрачный header накладывается на изображение. Постоянные H1 и описание находятся внутри hero на деликатной локальной тональной подложке; `1812.` в единственном H1 выделено бордовым цветом и размером. Подпись и ссылка на источник расположены справа внизу поверх картины, три компактные кнопки выбора слайда — по центру снизу. HeroSlider переключается автоматически примерно раз в 6500 ms, останавливается при наведении и фокусе с клавиатуры и полностью отключает autoplay при reduced motion; ручной выбор и touch swipe остаются доступны. Алфавит в превью словаря, даты и линия в превью хронологии, абстрактная сетка без географических утверждений в превью карты сохраняют собственные композиции. Линейки остальных секций показывают номера 02–04 без повторных текстовых labels. Если hero-файлы недоступны локально, показывается полноценная типографическая композиция без элементов слайдера. Stage 4–8 должны использовать ширины, шрифтовые роли, фокус, подписи и линии из этой системы. Полные карта и хронология получают собственные решения только на своих этапах.
