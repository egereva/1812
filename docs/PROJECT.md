# Проект

## Цель и аудитория

Создать доступный на телефоне и компьютере интерактивный справочник для школьного изучения Отечественной войны 1812 года. События охватывают всю войну; карта сосредоточена на проверенных исторических местах современного ЗАО Москвы. Содержание должно быть понятным старшекласснику и подтверждаться источниками.

## Границы

В составе проекта: иллюстрированный алфавитный словарь, хронология, карта, универсальные страницы материалов, тематическая страница «О проекте», перечень источников, русская и английская версии. Контент — локальные JSON, изображения — локальные файлы. Поиск, личный кабинет, админка, backend, база данных и тёмная тема не входят в проект.

Главная — последовательное знакомство со словарём, хронологией и картой. После полноэкранного hero с минимум тремя слайдами идёт краткое двуязычное историческое введение, затем три содержательные секции в указанном порядке. Каждая позволяет начать изучение и перейти к полной версии раздела.

## Страницы

| RU                   | EN                      | Назначение                             |
| -------------------- | ----------------------- | -------------------------------------- |
| `/`                  | `/en/`                  | Главная                                |
| `/dictionary`        | `/en/dictionary`        | Алфавитный словарь                     |
| `/dictionary/[slug]` | `/en/dictionary/[slug]` | Статья словаря                         |
| `/timeline`          | `/en/timeline`          | Полная хронология                      |
| `/timeline/[slug]`   | `/en/timeline/[slug]`   | Событие                                |
| `/map`               | `/en/map`               | Карта мест                             |
| `/places/[slug]`     | `/en/places/[slug]`     | Место или памятник                     |
| `/about`             | `/en/about`             | Историческая тема и логика справочника |
| `/sources`           | `/en/sources`           | Использованные источники               |

`[slug]` обозначает одно универсальное представление для каждого типа материала. URL не зависит от русского или английского заголовка.

## Основные сценарии

1. Ученик выбирает букву и переходит из списка или preview на главной сразу на полноценную страницу статьи Dictionary. Detail page — основной способ просмотра записи; дополнительный modal preview намеренно исключён из scope при финализации Stage 4, поскольку дублирует detail UX и добавляет промежуточный уровень. Это принятое изменение первоначального сценария, а не незавершённая задача. Связанные события и места относятся к последующим этапам.
2. Ученик проходит хронологию по датам. На широком экране она горизонтальна, на узком — вертикальна; главная показывает сокращённую часть и переход к полной.
3. Ученик открывает место на карте, читает карточку маркера, затем изучает страницу места, галерею, сравнение «тогда / сейчас», события и источники.
4. Пользователь меняет RU/EN и открывает соответствующую страницу на другом языке. Выбор запоминается между посещениями.
5. Редактор добавляет материал в JSON и связанные локальные медиа без изменения Vue-шаблонов; после пересборки появляется новый маршрут.

## Требования к качеству

- Исторические утверждения и атрибуции подтверждаются надёжными источниками. Непроверенные факты не публикуются как достоверные.
- Прямой вход на любую опубликованную страницу отдаёт её HTML, заголовок и описание; сайт не полагается на SPA fallback для SEO.
- Клавиатура, видимый фокус, семантический HTML, читаемый контраст и `prefers-reduced-motion` учитываются во всех интерактивных частях.
- Отсутствующее необязательное изображение или пустые связи не ломают страницу.
