# Интерактивный справочник: 1812 год и запад Москвы

Школьный исторический веб-проект для ученика 10 класса. Он связывает события Отечественной войны 1812 года с личностями, понятиями и историческими местами на территории современного Западного административного округа Москвы.

**Состояние:** RU и EN исторические наборы — final / production (по 13 мест, 29 статей, 20 событий и 25 источников). Структурный паритет локалей проверяется при сборке. Media audit готов; три approved hero-изображения интегрированы. Content Foundation, Stage 2 и Stage 3 (главная, три hero-слайда и безмедийный fallback) завершены. Stage 4 не начат.

Планируемый стек: Nuxt 4, Vue 3, TypeScript, npm, локальные JSON и изображения, Яндекс Карты. Сайт будет генерироваться как статический HTML для GitHub Pages. Исторические факты и права на изображения проверяются до публикации.

Для воспроизводимой установки используйте Node.js 22.23.3 (версия закреплена в [.nvmrc](.nvmrc)); в NVM for Windows переключение выполняется командой `nvm use 22.23.3`. Затем запустите `npm ci`. Для разработки и проверки: `npm run dev`, `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test`, `npm run build`, `npm run generate`. Требование `engines.node` исключает версии Node 22 ниже 22.22.2, несовместимые с установленной версией транзитивного пакета. Пример переменных сборки — [.env.example](.env.example).

## Принятые решения

1. Русские страницы используют `/`, `/dictionary`, `/timeline` и остальные маршруты без префикса; английские — `/en/...`.
2. Каждый опубликованный detail маршрут получает отдельный статический HTML; 62 RU и 62 EN detail маршрута формируются автоматически из контента.
3. JSON хранится отдельно от компонентов. Связи между материалами задаются стабильными ID, URL — стабильными slug.
4. Карта и её API работают в браузере; исторический текст, ссылки и SEO доступны в сгенерированном HTML.
5. `@nuxtjs/i18n` настроен для маршрутов и коротких UI-переводов; исторические материалы хранятся отдельно в `content/ru` и `content/en`. Pinia, CMS, backend и UI framework не нужны.
6. Основная дата событий 1812 года — по старому стилю; новый стиль и ключ сортировки хранятся явно, без неявного календарного преобразования.

`getDynamicPrerenderRoutes()` создаёт detail URL из JSON обеих production локалей без ручного списка. Правила редактирования и сохранения паритета приведены в [CONTENT.md](docs/CONTENT.md).

Технические основания: [структура Nuxt 4](https://nuxt.com/docs/4.x/directory-structure), [статическая генерация Nuxt](https://nuxt.com/docs/4.x/getting-started/deployment), [SEO Nuxt i18n](https://i18n.nuxtjs.org/docs/guide/seo), [загрузка Яндекс Карт](https://yandex.com/dev/jsapi-v2-1/doc/en/v2-1/dg/concepts/load).
